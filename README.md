# 급여 문서 작업실

엑셀 입력 양식의 기초정보와 설계명부를 업로드하여 급여 관련 엑셀·PDF를 생성하는 Windows 프로그램입니다.

## 다운로드

[최신 버전 다운로드 및 패치 노트](https://github.com/kim2611/salary-document-studio-releases/releases/latest)

GitHub 로그인 없이 다운로드할 수 있습니다. 처음 사용하는 PC에서는 Assets의 `SalaryDocuments-버전-windows-x64-full.zip`을 받으세요. 압축을 모두 풀고 폴더 안의 `급여문서작업실.exe`를 실행합니다. 실행 파일만 따로 옮기지 마세요.

Python, Excel, LibreOffice를 별도로 설치할 필요가 없습니다. Windows 64비트와 Microsoft Edge WebView2 런타임이 필요합니다.

## 업데이트 및 패치 노트

프로그램 실행 시 새 버전을 확인합니다. 앱의 **업데이트 확인 → 패치 다운로드 → 재시작하여 설치**로 업데이트할 수 있습니다. 다운로드와 설치는 사용자가 버튼을 눌러 진행합니다. 업데이트 후 작업할 엑셀은 다시 업로드해 주세요.

앱의 **패치 노트**에서 최신 변경 사항을 볼 수 있고, **GitHub 전체 패치 노트**로 이전 버전의 기록도 확인할 수 있습니다.

업데이트 기능이 없는 이전 프로그램은 처음 한 번 전체 배포본을 내려받아 사용하세요. `patch.zip`은 앱 업데이트용입니다.

이 저장소에는 공개 배포 파일과 변경 기록을 제공합니다. 개인 급여 자료는 포함하지 않습니다.
